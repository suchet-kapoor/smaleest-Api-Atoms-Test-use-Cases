What this demo actually does

Five mappings from the blog post to the production Atoms API. Open your browser devtools: every frame is real.

01

Create the agent

POST /agent only makes a shell. Prompt, voice, first message and tools are written to the Main branch draft, then published.

POST /agent                 → { data: agentId }
GET  /agent/:id/branches    → main branch
PUT  …/branches/:id/draft   → prompt + tools
POST …/draft/publish        → 202 scanning
GET  …/revisions            → until published
02

Token, not API key

The browser can’t hold your sk_… key. The server mints a single-use token that expires in 30 seconds, then the browser opens the socket with it.

POST /conversation/register-call
  { agent_id, input_audio_format, output_audio_format }
→ { access_token: "wct_…", expires_in: 30 }
03

Stream audio both ways

Microphone PCM is base64’d in input_audio_buffer.append frames. Replies arrive as output_audio.delta; we schedule them on an AudioContext so playback never waits for the whole reply.

↑ input_audio_buffer.append  { audio: "…" }
↓ output_audio.delta         { audio: "…" }
↓ transcript.delta / transcript  { role, text }
04

Barge-in is an event

Server-side VAD decides you started talking. The server emits interruption and the client must stop queued audio immediately. Try talking over a long answer.

↓ { "type": "interruption" }
   → stop every AudioBufferSourceNode
   → reset the playback clock
05

Client tools run in your app

The order lookup is a client_tool. Atoms sends function_call over the socket; this page calls the local fake order API and replies with function_call.result.

↓ function_call { call_id, name, arguments }
   → run your function
↑ function_call.result { call_id, output }
!

The blog is directionally right, not runnable

Its endpoints (atoms.smallest.ai/v1/agents, wss://…/stream) and fields (voice_id, model) don’t exist. Production uses api.smallest.ai/atoms/v1, branch-published agents, and input_audio_buffer.* frames.

This demo implements the real flow so you can compare.
